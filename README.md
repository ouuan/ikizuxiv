# ikizuXiv

[IKIZULIVE! LOVELIVE! BLUEBIRD](https://www.lovelive-anime.jp/lovehigh/) [いきづらい部！人生不易部！](https://x.com/i/lists/1921767698423521764)的 X 推文存档网站: https://ikizuxiv.ouuan.moe

"ikizuXiv" 的 "Xiv" 来自 "archive"[^arXiv]，读作 イキヅカイブ

[^arXiv]: (arXiv)

## 功能

-   按日期查看推文
-   中文翻译 / 注释
-   AI 配音（可自动播放）
-   搜索推文 / 按发布者筛选

数据为手动更新，非实时最新数据（比起追更，更适合批量补）

-   翻译、注释主要来自[羊驼](https://ikizutwizh.pikapaca.cc/)（已获得转载授权；做出来之后才发现对方也做了网站，经商议，我们均保留各自的网站）
-   使用 [prinsss/twitter-web-exporter](https://github.com/prinsss/twitter-web-exporter) 获取推文数据
-   目前使用 MiniMax 平台的 Speech 2.8 HD 模型配音
-   使用 [`scripts`](./scripts) 内的脚本导入数据
